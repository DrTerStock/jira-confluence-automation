# Weekly Status Report

- Write the report in Markdown format.
- Use only these sections: `## Accomplishments`, `## Blockers`, and `## Next Week`.
- Use bullet points only under each section.
- Keep the total report to a maximum of 20 lines.
- Use a professional, concise tone.
- Remove fluff words, filler phrases, and unnecessary commentary.
- Start with the most important accomplishments first.
- List blockers as clear issues, risks, or dependencies.
- Write next-week actions as specific, actionable work items.
- Keep each bullet short and factual.
- Do not include tables, paragraphs, or narrative text.
- Do not include emojis, greetings, or closing remarks.
- Ensure the output is clean, scannable, and ready to share with stakeholders.
